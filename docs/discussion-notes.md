- **已确认方向**：用户消息直接支持的项目意图，不等于已有可用实现。
- **已采纳**：用户在当前仓库讨论中同意的设计基线，不等于实现或验证完成。
- **已核对事实**：本次读取一手资料得到，有来源和核对日期。
- **提案**：为使需求可评审而补充，不代表原讨论已经同意。
- **待决策**：缺少证据且影响实现或公开承诺。

实现开始前，把被采纳的提案更新为“已采纳”，写明决策依据。补充来源应校正设计，不因文档已写成就保留与原意冲突的方案。

## 当前设计基线

按 D3/D4，以数据集表函数为用户入口，Rust 模块实现请求与规范化，DuckDB 绑定层输出固定关系。Python AKShare 用于语义参考和可选对照验证。当前已采纳的设计来自本仓库讨论，不归因于尚未读取到的原助手回复。

初稿中“Python 或原生二选一”“优先 C++ 模板”的建议已被这次补齐的需求替换。C++ 项目仍有参考价值；若 Rust 工程出现阻碍，应先记录并研究，不自动改写用户的 Rust 方向。

仍缺失：七条原助手回复及其引用资料。仍待验证或决策：候选来源与市场覆盖、单位换算证据、许可证、工程版本和目标平台。现有讨论不支持 AKShare 全量兼容、独立 Rust SDK 发布承诺，或某项上游 PR 已得到维护者同意。
