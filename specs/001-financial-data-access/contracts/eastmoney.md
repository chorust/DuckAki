# eastmoney 适配器协议与验证合同

这是 Rust 内部来源适配器的输入/输出约束，不是新公开 API。来源证据和限制见 [research.md](../research.md#r4协议单位和空结果分别校验)；用户合同见 [sql.md](sql.md)。

## 固定请求

生产 GET endpoint：`https://push2his.eastmoney.com/api/qt/stock/kline/get`。固定 HTTPS，不接受用户 URL。结构化编码参数，TLS 证书和主机名正常校验，任何非 2xx 失败，禁用自动重定向，不自动切换域名/来源。

| 参数 | 首版值/映射 |
| --- | --- |
| secid | sz000001 精确映射为 0.000001 |
| beg / end | 请求日期格式 YYYYMMDD，两端包含；本地再次筛选 |
| klt | 101（日线） |
| fqt | 0（不复权） |
| fields1 | f1,f2,f3,f4,f5,f6 |
| fields2 | f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61,f116 |

不附加猜测的 ut、cookie、凭据、分页或 lmt 参数；本次两个成功探测使用以上参数。适配器不是任意股票代码代理，仅支持已经确认的精确标的。最大日期和网络规模限额由 [sql.md](sql.md) 统一规定。

## 响应 envelope

完整正文为 JSON 对象；rc 必须为整数 0；data 必须为对象；code 必须为字符串 `000001`，market 为整数 0；klines 必须为数组。未知 envelope 元数据可忽略，不解释为行情。

- rc=0 + 正确身份 + klines=[]：合法零行。2024-01-06–07 的真实探测已观察到此形状。
- data=null、缺失身份、klines=null/缺失、非数组、非零/缺失 rc、返回错误标的：来源数据错误，不能猜“休市”。
- dktotal 为标的历史元数据，周末空区间也曾返回 8500，不等于本区间应有行数；不以它要求补行或推导截断。
- 一个请求应返回一个完整响应。无分页实现；HTTP/body 中断、可见继续页/截断标记、达到已确认的服务端限额而无法确认完整性时失败。不得将等待中的数据块输出为成功结果。

本次年度探测返回 242 条、每行 11 字段。请求 fields2 含 f116 不代表响应必有第 12 个行字段；初始协议锁定已观测和参考实现一致的 11 字段，数量变化先报告结构漂移，不静默按错位列解释。

## 行解析与标准输出

每项必须是逗号分隔字符串，按下列位置解释；不能用请求 symbol 覆盖错误的 envelope 身份。

| 位置（从 1 起） | 原始含义 | 标准处理 |
| --- | --- | --- |
| 1 | YYYY-MM-DD 日期 | 解析真实日期，最后按用户范围过滤 |
| 2 | 开盘 | open，有限 DOUBLE |
| 3 | 收盘 | close，有限 DOUBLE |
| 4 | 最高 | high，有限 DOUBLE |
| 5 | 最低 | low，有限 DOUBLE |
| 6 | 成交量（手） | 十进制精确 ×100，结果为非负 BIGINT 股数，检查非整数/溢出 |
| 7 | 成交额（元） | amount，有限非负 DOUBLE，不换汇 |
| 8–11 | 振幅/涨跌幅/涨跌额/换手率 | 不输出、不参与行情计算；保留协议字段位置校验 |

OHLC 缺失或不可解析失败；不补零，不修改价格。量额只在原站明确标记且已有来源依据时允许缺失；当前没有证据确认具体字符串缺失标记，因此原站行的空串/横线等先报错。内部可选字段的 NULL 保存与聚合仍以合成样例验证，不将合成格式声称为原站格式。

解析完成后，为每条输出加上 symbol、CNY、eastmoney、none，以及整批统一 fetched_at。批内 `(symbol, trade_date, source, adjustment)` 重复就失败，不能先 dedup。范围外的有效行过滤掉，坏行和重复记录不因在范围外而被掩盖。

价格和金额按分析用 DOUBLE，不额外施加未经需求采纳的价格正数或 OHLC 自动纠正规则。量额转换错误、未知单位或响应身份变化不允许降级成功。

## 适配器验证集

正常年度/短区间、同日、周末空数组、区间两端、前导零、手到股、可选值的内部 NULL；错误身份、data=null、空 body、HTML/坏 JSON、字段数变化、日期损坏、NaN/Infinity、量额溢出、重复（含完全相同重复）、超范围有效行，以及 HTTP 403/429/3xx、慢速滴流、正文中断和超限。

普通回归用自行构造的合成 fixture。测试专用 endpoint 仅在 test-support 构建启用并限制 loopback；生产不接受环境变量或 SQL 参数将请求指向任意服务器。测试请求次数和全部失败原因保留在测试驱动里，不引入产品日志服务。

## 来源登记与后续变化

完成 G1/G2 后才登记来源。依据 AKShare 固定版本文档、深交所单位材料和 Rust 端真实对照核验字段，记录标的、日期、单位依据、参数、时间、版本及结果摘要。真实响应的数据使用和再分发条件独立核对，默认不提交原始行情文件。

若来源结构或单位变化：失败 → 保留脱敏诊断 → 更新协议证据与 fixture → 通过回归后恢复声明。不能换名字掩盖来源口径差异，也不能在原来源失败时自动换源。
